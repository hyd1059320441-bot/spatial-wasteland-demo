# V11 八敌与爆头反馈

用户认可 V10，要求活敌从十个减少到八个，并增加爆头特效与音效。

- `GameRules.ACTIVE_ENEMIES` 为 8，总登场 100 与第 100 次击杀胜利保持。
  多点净空出生、独立机器人实例、代际移动、尸体 0.75 秒与原低敌伤保持。
- 真正命中头部并扣除敌人生命时触发专属反馈，非致死与致死均支持。
  胸核、身体、盾牌不触发专属爆头反馈。
- 头部附近新增九枚青金色碎光，持续 0.32 秒；沿来弹方向放在实际
  装甲边界外缘，近于 2 米缩小到一半，不使用大环或遮挡烟。
- 每枪同目标至多一个专属碎光；整枪只播放一次专属爆头音，
  避免霰弹枪多个弹丸叠加。原普通命中与爆头击杀提示保留。
- 音效为本项目原创合成 0.28 秒机械脆响和双音确认，
  `tools/generate_headshot_audio.py` 仅生成 `audio/headshot.wav`。
- 原生自检通过实际头部射线开火核验非致死/致死的特效与音效次数；
  规则回归覆盖八敌上限、百敌计数和霰弹去重。

交付证据在 `artifacts/2026-10-23-v11/`。
