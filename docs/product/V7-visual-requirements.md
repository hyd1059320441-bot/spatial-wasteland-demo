# V7：进场与交火时可见的升级

用户要求优先增加视觉效果，内容选择由开发者决定；隐藏玩法优先级降低。沿用 V6 的真实头显视点、等比场景、同一进入/开战地图与导航缓存修复。

| 内容 | 用户应能看见的变化 | 验收 |
| --- | --- | --- |
| 主路能源装置 | 出生后朝前左方能看见青色和暖白色细能源环，三环不同倾角转动，小亮点沿环运动；下方机座有奶油侧板、青色散热片和橙色防护柱 | 不要求先打通关；机座接地，主路可通行，环与机座分离 |
| 入口灯架与布旗 | 两座灯架建立近景尺度，灯条下方有暖色局部照明；四块垂挂布旗固定顶端，下部随风弯曲 | 行走区域净高不小于 3.6 米；暂停冻结，重启复位 |
| 道路细节 | 双轮胎磨损、补丁、横向格栅、路肩碎石和短管线，替代大面积无细节地表 | 磨损与格栅贴地，常用通路不受阻；静态细节按材质合并 |
| 交火层次 | 金属命中弹出有方向的细火花，地面命中有小碎屑；油桶爆炸包含短火焰、低矮弹片和短烟 | 近处火花缩小，不出现大闪球或死亡烟遮挡准星；暂停清空，有限对象池 |
| 比例与场景连续性 | 默认站立眼高 1.55 米；进入后看到的上述内容一直保留到开战 | 使用真实 HMD 位置，保持米制缩放；加载完成前不显示未校准地图 |

实现位置：`VisiblePolish.kt`、`ImpactVfx.kt`、`VisualGeometry.kt`。`V7Layout` 的机座和灯柱脚占地同时进入逻辑碰撞、原生碰撞、导航采样与缓存指纹。

Editor 的模型生成服务返回 `ASSET_PRODUCTION_UNAVAILABLE`。原定机座改为受管基础几何制作，保留配色、散热片、保护框和上方空腔。运行时能源环与原生灯光由 Kotlin ECS 驱动。

实现与 Editor 七视角检查已完成。新增内容全部在准备阶段加载，开战保持同一地图。
机座实测占地 3.0 × 2.571 米，表面底部 Y=0.24 米，与底座顶部一致；
入口灯条下沿 3.602 米。原生胶囊实测半径 0.280 米、总高 1.650 米、长轴 Y。

启动回归额外发现导航缓存校验把任意位置与取整后的网格单元比较，导致有效缓存每次被拒绝。
已改为重测该单元实际存储的 0.5 米采样点；保留指纹、CRC 与原生物理失配拒绝。
修正后四次新进程均命中磁盘缓存，启动 4.846 / 3.702 / 4.062 / 3.761 秒，
导航 153 / 120 / 127 / 124 ms。见 `artifacts/2026-10-22-visual/startup-cache/`。

最终构建通过 86 项单测，设备验收与最终安装记录见本轮 `delivery.md`。
头显中的外观与真人比例感由用户亲自确认；不以文件数或测试数代替视觉验收。
GPU/帧预算的实测和限制另行记录，不宣称性能瓶颈已解决。
