# V8 美漫射击体验重做

用户明确否定 V7 的迷你集装箱、视点调节与拾枪流程；要求正常物体比例、
默认持枪、降低刺眼亮度、通过 Editor MCP 真正生成场景模型与不同机器人，
武器与机体融合，并增加炫酷战斗特效。本文件替代 V6/V7 与这些要求冲突的部分。

## 尺度与基础行为

- 世界坐标继续使用米，root 保持单位缩放。成人角色以 1.75 米身体、
  1.65 米站立眼位作为默认设计基准，保留真实蹲起与头向移动。
  删除高度调节/重新校准按钮、命令、持久化偏好；自动初始化追踪参考。
- 集装箱以常用 20 英尺外部尺寸 6.058 × 2.438 × 2.591 米为依据。
  不把集装箱缩成腰高掩体。通路、碰撞、导航和掩体布局同步调整。
- 维修棚是可容纳正常成人与设备的工业建筑；门口净高约 2.2～2.4 米，
  建筑整体按用途与模型原比例决定，不把原建筑整体缩成微缩玩具。
- 枪默认在右手，两个武器与各自弹匣可直接使用。删除装备架/拾枪任务，
  无装备拾取、终端交互前置条件。保留既有暂停、退出与明确开战流程。
- 降低太阳、填充光与近景灯的强度，减少大面积纯白/高亮表面；
  保持敌人、地面和枪械可读。避免靠降低整个 UI 对比度解决场景眩光。

## 真正的 Editor 模型生成

所有以下资产采用 `generate_fresh`，使用 Editor MCP 管理生成与导入。
生成服务不可用时记录实际错误，不把 primitive/Kotlin 方块拼装计为完成。

| 资产 | 生成方向与拟定尺度 |
| --- | --- |
| 重火力机器人 | 约 2.1 米，宽肩、背部供弹箱，连续机械连接的前臂旋转炮 |
| 突击机器人 | 约 1.8 米，灵活长腿，双前臂内置能量枪，轮廓轻快 |
| 盾卫机器人 | 约 2.0 米，厚甲、臂盾安装座，与肩/上臂连接的炮；最终生成版本采用此结构 |
| 狙击机器人 | 约 1.95 米，瘦长机身、长管前臂炮与机体一体的瞄具 |
| 战斗无人机 | 约 1.4 米翼宽，机械旋翼/推进器与下置武器一体 |
| 标准集装箱 | 正常 20 英尺尺寸，门、锁杆、波纹钢板与端部结构 |
| 维修服务车 | 约 6 米长的正常工业车辆，车厢、轮胎和驾驶室明确 |
| 废土加油/维修装置 | 正常人体尺度的泵、管线、阀门与棚架组件 |

统一美漫视觉：强轮廓、硬朗装甲块面、清晰明暗分区、克制的绘制墨线与磨损，
哑光钢材、橙色警戒标记、青蓝局部能量颜色，避免通体发白与泛光刺眼。
敌人武器须从多个视角证明与身体相连，并在移动/攻击动画中保持连接。
生成后用真实 bounds 确定落地、等比缩放、朝向、碰撞和枪口位置。
保留活动动画；不能把新模型当作移动的静止雕像交付。

## 战斗特效

- 玩家枪口：短促分层火光/能量喷发与后坐反馈，避免持续白色闪屏。
- 命中：按金属/地面/机器人区分火花、碎片与小型能量裂解。
- 敌人攻击：前臂蓄能、可识别弹道尾迹，攻击方向明确。
- 油桶/敌人重击：有层次的火焰、冲击波、烟和碎屑，近处控制闪光与遮挡。
- 特效使用有限资源池，暂停清空瞬态效果，保持瞄准线清楚。

记录实际启动与帧预算；不以测试数、文件数或资产导入成功代替视觉质量。
不要求头显截图，不自动提 MeeGo，不修改 ROM 或公共 Spatial SDK 6.2.6。

生成资产与应用整合记录见 `artifacts/2026-10-22-v8/`。重装源的多管炮和盾卫
肩炮为已检查、验收的真实生成结构；不要求补生成助手先前建议的精确枪管数量或臂侧。

破坏后留下机体和安装结构。入口增加维修车与加油站，十一处集装箱按工业尺寸呈现。
