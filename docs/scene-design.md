# 废土靶场：第一版实现范围

目标：使用 PICO Spatial SDK 6.2.6 创建原创漫画风的小型第一人称射击场景。用户已授权直接实现新工程；本版本是可运行概念原型。

## 体验与结构

- Full Space Stage，玩家真实头部与右手柄姿态控制观察和瞄准。
- 玩家在原点附近站立，竞技场沿 -Z 展开；所有世界坐标单位为米。
- 地面、围栏、岩石和机器人为本项目原创程序化几何；枪械和箱子来自 Kenney Blaster Kit 2.1（CC0）。
- 右手扳机射击，A 键换弹，B 键暂停/恢复。弹匣 12 发，换弹期间不可射击。
- 机器人从远处进入，受到三次身体命中或一次头部命中后倒下；接近玩家时进行间隔攻击。
- 清空一波后进入下一波；玩家生命值耗尽后显示重新开始入口。
- 准星/激光、枪口闪光、命中火花、血条、击杀计数和原创合成音效提供反馈。
- 2D UI 只用 SpatialUI + PicoTheme，并作为 Stage 的 AttachmentPanel；不使用 Material/Material3。

## 设计选择

比较三种体验：平面游戏窗口、桌面微缩战场、第一人称 Stage。选择 Stage，因为真实手柄方向、距离判断和立体敌人是核心任务；平面窗口弱化这些能力，微缩战场更适合第三人称策略操作。

第一版保持真实空间站位，不添加摇杆人工移动或跟随相机。漫画感由低多边形轮廓、原创黑色装甲边缘和沙色/橙色/青色材质建立；不承诺原作渲染一致性。

## 场景关系

- 地面顶部 Y=0，所有静态道具通过加载后的视觉边界调整到底面接地。
- 主场地 X=[-8,8]、Z=[-16,4]；敌人从 Z=-10 附近沿通道前进。
- 左右箱子保持在射击通道两侧，中心通道避免与静态掩体重叠。
- 枪械跟随右手柄；枪口锚点与命中射线使用同一 Stage 坐标。
- HUD 位于镜头前方较低处，避免盖住中心瞄准区域。
- 敌人、武器、火花等动态对象按帧更新；实体和资源只在初始化时创建并复用。

## 状态与验收

状态：加载 → 就绪 → 战斗 ↔ 暂停；战斗 → 换弹 → 战斗；生命值耗尽 → 结束 → 重新开始；资源失败 → 可重试错误提示。

验收：依赖解析为 6.2.6、APK 构建成功、真机可启动、无应用 crash/ANR、加载资源成功、游戏规则边界测试通过。真实扳机瞄准及视觉舒适度由真机操作确认，不能仅以编译结果判定通过。
