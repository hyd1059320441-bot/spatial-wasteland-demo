# 第二版：废弃矿区前哨战

用户已明确批准按第二版建议开始开发。沿用现有工程、包名、Full Space Stage 和 Spatial SDK 6.2.6 正式版。

## 体验

一个可探索的小型前哨，目标流程为清理营地、启动发电机、进入机库、击败精英、开启战利品箱。用贴图模型、角色骨骼动画、建筑与设备替代第一版的简易靶场表现。

- 去掉持续激光，使用枪口方向的四角准心。准心位于最近命中表面前方，保持稳定的角尺寸；射击扩散、命中短闪、爆头反馈。
- 自动步枪与霰弹枪，具有不同弹匣、射速、散布、后坐、枪机/泵动、退壳、换弹动作、音效与右手震动。
- 冲锋敌人、利用掩体的远程敌人、装甲精英。采用实际带动画的模型，攻击包含预备动作，死亡不再挡住射线。
- 左手瞬移、右手分段转向。移动落点须在可通行区域，不能进入墙体、货箱或越过尚未打开的机库门。
- 建筑、管道、屏幕、设备、残骸、岩石与地面贴图形成近中远景；维持沙色、铁灰、橙色和青色的统一视觉。
- 可爆油桶造成范围伤害；精英掉落电击武器升级，拾取后出现两名增援供玩家实际使用电击属性，清理后战利品箱完成本局。电击短暂停顿并打断攻击预备。

## 控制与 UI

| 输入 | 行为 |
| --- | --- |
| 右扳机 | 步枪按住连射；霰弹枪扣动一次射击一次 |
| 右 A | 换弹；结束时重新开始 |
| 右 B | 暂停 / 继续 |
| 左 X | 切换武器 |
| 左 Y | 与近处发电机、升级掉落和宝箱交互 |
| 左摇杆向前保持，再松开 | 以左手朝向选择地面落点并瞬移 |
| 右摇杆左右 | 每次偏转转向 30°，回中后可再次转向 |

HUD 仍为相机下方的 SpatialUI AttachmentPanel，显示生命、武器/弹药、任务目标、击杀和短反馈，提供换弹、切枪、交互、暂停和重开。按钮前景继承组件色，PicoTheme 调色板保持原生。

暂停、后台或必要手柄姿态丢失时，战斗计时、动画、敌人弹道与交互进度停止。指向 HUD 不射击。重新开始恢复任务、门、油桶、掉落、敌人和玩家初始位置。

## 场景与程序结构

- 命名世界根实体拥有静态场景、角色、命中体、效果和手持枪的世界坐标。相机 HUD 独立锚定。
- 瞬移/转向改变虚拟世界相对玩家的根变换；通过 SDK 公共坐标转换保持手柄、准心、射线和游戏世界一致。
- 初始站位附近为入口与维修棚，中庭有掩体和发电机，深处为机库与战利品。用独立布局数据定义导航区域、障碍、门和互动距离。
- 游戏规则为纯 Kotlin；SDK 场景桥接、环境构建、武器表现和动画角色分文件维护。实体、网格、材质和效果池仅初始化创建，按帧更新不加载文件。
- GLB 采用作者原始 glTF/GLB；如需转换，只进行离线打包、嵌入外部纹理、去除多余导出节点和切分动画，不猜单位、朝向或骨骼语义。记录源码与运行时边界。

## 资源与验证

优先使用 Quaternius 官方 CC0 资源的免费版本：Sci-Fi Essentials Kit、Modular Sci-Fi MegaKit；需要时使用 Toon Shooter Game Kit。筛选完成后记录每个运行时资产、原包路径、许可、哈希、边界和动画清单。原作《无主之地》资产未取得嵌入 APK 的明确许可，不作为本版依赖。

验收包括：正式版依赖解析、APK 构建、战斗/任务/换弹/伤害/移动边界测试、完整资产引用、真机模型与动画加载、SDK 射线与遮挡、任务和重启自检、无新增应用 crash/ANR。画面、真实手柄、震动、舒适度和帧率按真机证据报告，未观察项不宣称通过。
